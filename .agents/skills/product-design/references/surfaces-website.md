# Landing page surface

Load when reviewing or changing the public landing page.

Keep claims factual and consistent with the current product. Do not invent
metrics, customer names, integrations, or capabilities.

## Content and interaction

- State the user problem and product value in direct language.
- Make the primary next step clear.
- Use real product evidence where available.
- Keep navigation, links, and buttons distinct by purpose.
- Respect reduced-motion preferences.
- Ensure the page works on narrow and wide viewports.

## Coverage

Check the first viewport, navigation, calls to action, keyboard use, and
responsive layout. Check long strings and loading behavior for external
content.
